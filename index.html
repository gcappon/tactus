A metronome built for the stage.

Sample-accurate click, set lists that advance on their own, and a full-screen view you can read from across the room.

  • Accents on every beat, any meter from 1 to 16, odd-time presets (5/4, 7/8, 9/8, 12/8)
  • Subdivisions, swing, gallop and other rhythm patterns; silent-bar practice
  • Tap tempo and a tempo wheel, 20–300 BPM
  • Stage mode: stop after N bars, count-in, then load and start the next song
  • Multiple set lists, drag to reorder, foot-pedal page turners supported
  • 14 sounds with an equalizer, plus your own custom sounds
  • English, Italiano, Deutsch, Español, Français, 日本語 — light and dark
